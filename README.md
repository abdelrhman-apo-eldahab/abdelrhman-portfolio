# Abdelrhman Rafaat — Portfolio

Personal portfolio site for Abdelrhman Rafaat, Media Buyer in Cairo (Facebook & Instagram ads, tracking, A/B testing, scaling).

`index.html` plus screenshots in `assets/` — open it in a browser, or deploy with GitHub Pages:
**Settings → Pages → Deploy from branch → `main` / root**.

`js/lenis.min.js` is [Lenis](https://github.com/darkroomengineering/lenis) 1.1.13 (MIT), used for smooth scrolling.
